# 帳票の画像出力

メーターと再発行画面から作成する安全運転レポートは、A4 縦（1240 × 1754 px）の PNG 画像として共有ストレージの `Pictures/TaxiJokeMeter` に保存する。保存が完了してから、保存した画像を Android の共有シートで開く。共有シートを閉じても画像は写真アプリに残る。

速度グラフの下に、急加速・急減速・速度超過の時間帯を同じ時間軸で表示する。帯の両端は記録したイベントの開始・終了時刻に対応する。警告の種類ごとに行とカラーユニバーサルデザイン推奨色を割り当て、急加速は点線、急減速は太い実線、速度超過は斜線で示す。一般道と高速道路の基準線も線種を変え、グレースケールで区別できるようにする。明細にも開始・終了時刻を表示する。

安全イベントと実車営業の明細は、それぞれ先頭から用紙に収まる行を最大14件まで表示する。残りがある場合は明細の末尾に件数を表示する。

走行レシートの画像と PDF は、使用するフォントで行の幅を測り、長い住所や明細を用紙の幅に合わせて折り返す。
